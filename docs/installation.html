Cài đặt

Chạy CoworkerAPI từ mã nguồn.

Yêu cầu

  • Node.js 22.14 trở lên và npm.
  • Mã nguồn CoworkerAPI trên máy của bạn.
  • Tài khoản ChatGPT có quyền dùng plugin/MCP Apps.
  • tunnel-client nếu kết nối ChatGPT qua tunnel.

Build và mở launcher

Mở terminal tại thư mục repository, sau đó chạy:

cd coworkerAPI-dashboard
npm ci
npm run build
node bin/coworkerapi.mjs

Launcher khởi tạo cấu hình nếu chưa có. Chọn mở dashboard và truy cập địa chỉ được in trong terminal. Giữ terminal mở để dịch vụ tiếp tục chạy.

Đăng nhập dashboard

Mật khẩu local ban đầu là 123456. Để đặt mật khẩu khởi tạo khác, cấu hình COWORKER_ADMIN_PASSWORD trước lần chạy đầu tiên. Mật khẩu đã lưu được giữ nguyên; biến này không thay đổi mật khẩu hiện có. Giữ trang quản trị trên máy local. Mật khẩu quản trị không phải API key của client.

Lệnh toàn cục

Để gọi launcher bằng coworkerapi, chạy lệnh sau trong thư mục coworkerAPI-dashboard:

npm link
coworkerapi

Windows là nền tảng chính. Launcher có cơ chế mở trình duyệt cho macOS, Linux và Termux, nhưng cài tunnel và lưu secret bằng DPAPI hiện yêu cầu Windows. Không xem các nền tảng khác là luồng bridge đã được hỗ trợ đầy đủ.

Cập nhật

Sao lưu cấu hình và dữ liệu runtime, dừng dịch vụ, cập nhật mã nguồn rồi chạy lại npm ci và npm run build. Không chạy nhiều gateway với cùng Tunnel ID.

Installation

Run CoworkerAPI from source.

Requirements

  • Node.js 22.14 or newer and npm.
  • A local copy of the CoworkerAPI source.
  • A ChatGPT account with plugin/MCP Apps access.
  • tunnel-client when connecting ChatGPT through a tunnel.

Build and open the launcher

From the repository directory, run:

cd coworkerAPI-dashboard
npm ci
npm run build
node bin/coworkerapi.mjs

The launcher initializes configuration when needed. Choose the dashboard option and open the address printed in the terminal. Keep the terminal open to keep the service running.

Sign in to the dashboard

The initial local password is 123456. To set a different initial password, configure COWORKER_ADMIN_PASSWORD before the first start. Existing passwords are preserved; this variable does not reset an existing password. Keep administration local. The admin password is separate from the API key used by clients.

Global command

To open the launcher with coworkerapi, run this inside coworkerAPI-dashboard:

npm link
coworkerapi

Windows is the primary platform. The launcher has browser-opening support for macOS, Linux, and Termux, but tunnel installation and DPAPI-protected secret storage currently require Windows. This does not imply a fully supported bridge flow on other platforms.

Update

Back up configuration and runtime data, stop the service, update the source, and run npm ci and npm run build again. Do not run multiple gateways with the same Tunnel ID.
