Thay đổi

Ghi chú phát hành CoworkerAPI.

1.0.0

Bản phát hành đầu tiên.

  • Endpoint OpenAI-compatible cho Responses và Chat Completions; Anthropic-compatible cho Messages.
  • Bridge ChatGPT dùng plugin MCP và widget kích hoạt trong hội thoại.
  • Dashboard Việt/Anh, giao diện sáng/tối và hướng dẫn thiết lập.
  • Quản lý API key, model alias, request log, usage và cập nhật realtime.
  • Launcher terminal và luồng cài đặt từ mã nguồn.

Trước khi cập nhật

Đọc ghi chú đi kèm phiên bản, sao lưu cấu hình, dữ liệu và khóa mã hóa. Tương thích endpoint không đồng nghĩa mọi chức năng client đều được hỗ trợ. Kiểm tra lại bridge và một yêu cầu ngắn sau mỗi lần cập nhật.

Changelog

CoworkerAPI release notes.

1.0.0

Initial release.

  • OpenAI-compatible Responses and Chat Completions endpoints; Anthropic-compatible Messages.
  • A ChatGPT bridge using an MCP plugin and conversation-activated widget.
  • English/Vietnamese dashboard, light/dark themes, and setup guidance.
  • API keys, model aliases, request logs, usage, and live dashboard updates.
  • A terminal launcher and source installation flow.

Before updating

Read the notes accompanying each version and back up configuration, data, and the encryption key. Endpoint compatibility does not imply support for every client feature. Recheck the bridge and send a short request after each update.
