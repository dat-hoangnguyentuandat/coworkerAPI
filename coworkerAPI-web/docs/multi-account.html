Cấu hình client

Chọn giao thức mà công cụ của bạn hỗ trợ.

OpenAI-compatible

Trong client có custom provider, nhập base URL http://127.0.0.1:3211/v1, API key CoworkerAPI và model chatgpt-web. Client dùng Bearer authentication. Tùy công cụ, chọn Chat Completions hoặc Responses API.

Anthropic-compatible

Dùng base URL http://127.0.0.1:3211, không thêm /v1. Route Messages là POST /v1/messages. Client có thể xác thực bằng x-api-key.

Claude Code

Trong file cấu hình người dùng ~/.claude/settings.json (Windows: %USERPROFILE%\.claude\settings.json), gộp các biến sau vào mục env hiện có, không ghi đè cấu hình khác:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:3211",
    "ANTHROPIC_AUTH_TOKEN": "<API_KEY>",
    "ANTHROPIC_MODEL": "chatgpt-web"
  }
}

Khởi động lại Claude Code sau khi thay đổi. Đây là cấu hình custom endpoint, không phải đăng nhập bằng tài khoản Claude hoặc chuyển đổi gói thuê bao.

Cursor, VS Code, OpenCode và công cụ khác

Chọn provider tùy chỉnh nếu công cụ hỗ trợ, rồi dùng endpoint, key và model tương ứng. Tên trường và các tham số bắt buộc có thể khác giữa các phiên bản. Kiểm tra một yêu cầu ngắn trước khi cho client chạy task nhiều bước.

Model alias và tài khoản

Model alias là tên định tuyến của gateway, không phải cam kết dùng model native cùng tên. Một tên model Claude không biến upstream thành Claude. Trang này không cung cấp profile đa tài khoản hoặc đăng nhập native Codex/Claude.

Client configuration

Choose the protocol your client supports.

OpenAI-compatible

In a client supporting custom providers, set the base URL to http://127.0.0.1:3211/v1, use a CoworkerAPI key, and select chatgpt-web. Authentication uses a Bearer token. Choose Chat Completions or Responses according to your client.

Anthropic-compatible

Use http://127.0.0.1:3211 as the base URL, without /v1. The Messages route is POST /v1/messages. Clients may authenticate with x-api-key.

Claude Code

In your user settings file, ~/.claude/settings.json (Windows: %USERPROFILE%\.claude\settings.json), merge these variables into the existing env object without replacing other settings:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:3211",
    "ANTHROPIC_AUTH_TOKEN": "<API_KEY>",
    "ANTHROPIC_MODEL": "chatgpt-web"
  }
}

Restart Claude Code after changing settings. This uses a custom endpoint; it is not a native Claude account login or a subscription conversion.

Cursor, VS Code, OpenCode, and other tools

Select a custom provider where supported, then enter the corresponding endpoint, key, and model. Field names and required parameters can vary between client versions. Test a short request before running a multi-step task.

Model aliases and accounts

A model alias is a gateway routing name, not a promise to use a native model with that name. A Claude model name does not make the upstream Claude. This page does not provide multi-account profiles or native Codex/Claude sign-in.
