Kết nối ChatGPT

Thiết lập một tunnel và kích hoạt bridge.

Thiết lập tunnel

ChatGPT cần truy cập endpoint MCP từ bên ngoài máy của bạn. Mở Kết nối trong dashboard và dùng form tunnel để nhập đường dẫn tunnel-client, Tunnel ID và API key theo hướng dẫn hiển thị. Không cần chỉnh .env cho luồng thiết lập thông thường.

Hướng dẫn trong dashboard có ảnh và link cho từng bước. Khi tạo key trên trang API keys, chọn Create new secret key, chọn Project và quyền phù hợp với tài khoản. Key này dành cho tunnel; không phải key CoworkerAPI bạn cấp cho client.

Thêm plugin

Dùng URL MCP do dashboard cung cấp, thay vì tự suy đoán địa chỉ. Trong phần ứng dụng/plugin của ChatGPT, tạo kết nối có tên CoworkerAPI. Bật chế độ dành cho nhà phát triển nếu tài khoản yêu cầu.

Kiểm tra danh sách công cụ có workbench_api_activate. Nếu không thấy, kiểm tra lại endpoint, xác thực MCP và quyền truy cập của tài khoản.

Kích hoạt hội thoại

  1. Chọn mở bridge trong ChatGPT từ dashboard.
  2. Trong hội thoại được mở, gửi tin nhắn kích hoạt đã điền sẵn.
  3. Chờ widget xuất hiện và trạng thái bridge chuyển sang Ready.
  4. Giữ hội thoại và widget mở trong khi client đang chạy.

Giữ một kết nối hoạt động

Hướng dẫn này sử dụng một gateway và một tunnel. Không mở thêm instance có cùng Tunnel ID: callback có thể tới instance không giữ request. Nếu bridge mất kết nối, kiểm tra tunnel rồi mở lại link kích hoạt.

Connect ChatGPT

Set up one tunnel and activate the bridge.

Configure the tunnel

ChatGPT needs to reach the MCP endpoint from outside your machine. Open Connections in the dashboard and use the tunnel form to enter the tunnel-client path, Tunnel ID, and API key as directed. The normal setup flow does not require editing .env.

The dashboard guide includes screenshots and links for each step. On the API keys page, choose Create new secret key, select a Project, and choose permissions available to your account. This key is for the tunnel, not the CoworkerAPI key issued to clients.

Add the plugin

Use the MCP URL shown in the dashboard rather than constructing it yourself. In ChatGPT's app/plugin settings, add a connection named CoworkerAPI. Enable developer mode if required for your account.

Confirm that the tool list includes workbench_api_activate. If it is missing, check the endpoint, MCP authentication, and account permissions.

Activate a conversation

  1. Open the ChatGPT bridge link from the dashboard.
  2. Send the prefilled activation message in the new conversation.
  3. Wait for the widget to appear and the bridge status to show Ready.
  4. Keep the conversation and widget open while your client runs.
Use the CoworkerAPI plugin tool workbench_api_activate now to open the CoworkerAPI bridge widget in this new chat.

Keep one connection active

This guide uses one gateway and one tunnel. Do not start another instance with the same Tunnel ID: callbacks may reach an instance that does not hold the request. If the bridge disconnects, check the tunnel and reopen the activation link.
