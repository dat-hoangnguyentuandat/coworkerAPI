Bảo mật

Giữ quyền quản trị và thông tin xác thực ở máy local.

Ba loại thông tin xác thực

  • Mật khẩu dashboard: bảo vệ trang quản trị. Mật khẩu local ban đầu là 123456; đặt COWORKER_ADMIN_PASSWORD trước lần chạy đầu tiên để dùng mật khẩu khởi tạo khác. Mật khẩu hiện có được giữ nguyên. Giữ quản trị trên máy local.
  • API key CoworkerAPI: cấp cho client để gọi endpoint. Tạo key riêng cho từng công cụ và thu hồi khi không còn dùng.
  • MCP secret và key tunnel: phục vụ kết nối ChatGPT; không chia sẻ với client hoặc đưa vào ảnh hướng dẫn.

Phạm vi mạng

Giữ gateway trên 127.0.0.1 khi chỉ dùng trên một máy. Dùng tunnel cho kết nối ChatGPT. Không công khai dashboard hay mở cổng ra Internet nếu chưa thiết kế xác thực, TLS và giới hạn truy cập phù hợp.

Dữ liệu và sao lưu

Thông tin xác thực lưu qua dashboard được mã hóa. Sao lưu cấu hình và dữ liệu runtime cùng khóa mã hóa MASTER_ENCRYPTION_KEY ở nơi an toàn. Mất khóa có thể khiến thông tin xác thực đã lưu không giải mã được.

Không commit .env, thư mục runtime, API key, cookie, session browser, log nhạy cảm hoặc ảnh chụp chứa thông tin xác thực lên GitHub. Kiểm tra nội dung file trước khi chia sẻ log.

Key tunnel được bảo vệ bằng Windows DPAPI, gắn với tài khoản Windows hiện tại. Bản sao file cấu hình có thể không giải mã được trên tài khoản hoặc máy khác; khi chuyển máy, nhập lại key tunnel. MASTER_ENCRYPTION_KEY dành cho secret provider, không thay thế khóa DPAPI.

Quyền thực thi

Claude Code và các client có quyền đọc hoặc chạy lệnh theo cơ chế cấp quyền của chính client. Chỉ cho phép thao tác bạn hiểu rõ và tin tưởng. Một endpoint tương thích không tạo sandbox cho tool local.

Giới hạn dịch vụ

Tuân thủ điều khoản áp dụng cho tài khoản và các dịch vụ kết nối. CoworkerAPI không được OpenAI hoặc Anthropic chứng thực và không cung cấp cách bỏ qua quota, quyền truy cập hay chính sách dịch vụ.

Security

Keep administration and credentials local.

Three credential types

  • Dashboard password: protects administration. The initial local password is 123456; set COWORKER_ADMIN_PASSWORD before the first start for a different initial password. Existing passwords are preserved. Keep administration local.
  • CoworkerAPI key: authorizes client requests. Issue a separate key for each tool and revoke keys you no longer use.
  • MCP secret and tunnel key: connect ChatGPT to the bridge. Do not share these with API clients or include them in guide screenshots.

Network exposure

Keep the gateway bound to 127.0.0.1 for single-machine use. Use the tunnel for ChatGPT connectivity. Do not expose the dashboard or open the service to the Internet without appropriate authentication, TLS, and access limits.

Data and backups

Credentials saved through the dashboard are encrypted. Back up configuration and runtime data together with MASTER_ENCRYPTION_KEY in a secure location. Losing that key can prevent stored credentials from being decrypted.

Never commit .env, runtime data, API keys, cookies, browser sessions, sensitive logs, or credential-bearing screenshots to GitHub. Review file contents before sharing logs.

Tunnel keys use Windows DPAPI protection tied to the current Windows user. A copied settings file may not decrypt under another user or machine; re-enter the tunnel key when migrating. MASTER_ENCRYPTION_KEY protects provider secrets and does not replace DPAPI protection.

Execution permissions

Claude Code and other clients read files or run commands using their own permission controls. Approve only actions you understand and trust. A compatible endpoint does not sandbox local tools.

Service boundaries

Follow the terms applicable to your account and connected services. CoworkerAPI is not endorsed by OpenAI or Anthropic and does not bypass quotas, access requirements, or service policies.
