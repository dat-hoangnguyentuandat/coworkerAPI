Tổng quan

Đưa ChatGPT vào công cụ bạn đang sử dụng.

CoworkerAPI là gateway chạy trên máy của bạn, cung cấp endpoint tương thích OpenAI và Anthropic. Yêu cầu từ công cụ được chuyển đến widget MCP trong ChatGPT; kết quả được chuyển về định dạng mà công cụ có thể đọc.

Luồng xử lý

Client → CoworkerAPI → ChatGPT MCP widget
       ← API response ← ChatGPT

Client vẫn quản lý workspace và thực thi công cụ local. CoworkerAPI chuyển tiếp yêu cầu và kết quả; không thay thế cơ chế cấp quyền của client.

Bắt đầu

  1. Cài đặt từ mã nguồn và mở dashboard.
  2. Kết nối ChatGPT bằng tunnel và plugin MCP.
  3. Gửi yêu cầu đầu tiên với API key của CoworkerAPI.

Phạm vi hỗ trợ

Các route hiện có: POST /v1/responses, POST /v1/chat/completions, POST /v1/messages và GET /v1/models. Mặc định dùng model alias chatgpt-web.

Giới hạn cần biết

Bridge hiện là tính năng thử nghiệm. Giữ hội thoại kích hoạt và widget mở trong suốt phiên sử dụng. Widget xử lý yêu cầu theo lượt; SSE cho client phát sau khi nhận kết quả hoàn chỉnh, không phải token streaming trực tiếp từ ChatGPT.

CoworkerAPI không phải API ChatGPT chính thức, không bảo đảm hỗ trợ toàn bộ tham số của OpenAI hoặc Anthropic và không loại bỏ giới hạn tài khoản. Quyền truy cập plugin phụ thuộc tài khoản và các tính năng ChatGPT hiện có.

Overview

Connect ChatGPT to the tools you already use.

CoworkerAPI is a gateway running on your machine with OpenAI-compatible and Anthropic-compatible endpoints. Client requests reach an MCP widget in ChatGPT; completed results are translated into the format your client expects.

Request flow

Client → CoworkerAPI → ChatGPT MCP widget
       ← API response ← ChatGPT

Your client still manages the workspace and runs local tools. CoworkerAPI forwards requests and results; it does not replace the client's permission controls.

Get started

  1. Install from source and open the dashboard.
  2. Connect ChatGPT through a tunnel and MCP plugin.
  3. Send your first request using a CoworkerAPI key.

Supported routes

Available routes: POST /v1/responses, POST /v1/chat/completions, POST /v1/messages, and GET /v1/models. The default model alias is chatgpt-web.

Current limitations

The bridge is experimental. Keep the activation conversation and widget open while using the client. The widget processes requests in sequence. Client SSE events are emitted after a complete result arrives, not as live tokens from ChatGPT.

CoworkerAPI is not an official ChatGPT API, does not guarantee support for every OpenAI or Anthropic parameter, and does not bypass account limits. Plugin access depends on your account and available ChatGPT features.
